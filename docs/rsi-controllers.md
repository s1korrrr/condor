# RSI Modular

The public `rsi_modular` controller requires an explicit immutable `ok_rsi` or
`rsi_v5` profile. Condor requests the selected profile's genuine native schema,
keeps profile identity in saved configurations and Telegram configuration rows,
and forwards source seals through its authenticated deployment helper. Legacy
modular names remain supported. A profile change invalidates the native recipe
binding; it does not migrate existing capital or recorder ownership.
